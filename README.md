## 📖 Sobre o Projeto

Projeto criado para atividade do segundo semestre de Ciências da computação pela FIAP. O objetivo é organizar dados operacionais e de comunicação da Aurora Siger, analisar dados, permitir consultas, configurar alertas e realizar o relatório técnico. 

## ✨ Funcionalidades

* \[1\] Alertas (Mostra os 5 alertas mais críticos)

* \[2\] Visualização dos dados

* \[3\] Métricas e análise (Geração de gráficos e análise) 

* \[4\] Sistema de busca na base de dados

* \[5\] Adição de linhas ao dataset

## 🛠 Tecnologias Utilizadas (Bibliotecas auxiliares)
